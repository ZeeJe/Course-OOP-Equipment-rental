# Інструкція з контриб'ютингу (CONTRIBUTING)

Дякуємо за інтерес до проекту! Щоб внести свої зміни:

1. Зробіть **Fork** цього репозиторію.
2. Створіть нову гілку для своєї фічі: `git checkout -b feature/назва-фічі`.
3. Внесіть зміни та проведіть локальне тестування.
4. Зробіть комміт змін: `git commit -m 'Додано нову функціональність'`.
5. Відправте зміни у свій форк: `git push origin feature/назва-фічі`.
6. Створіть **Pull Request** до основної гілки `main`.
